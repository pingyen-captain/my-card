Project

賦力

銀髮到府健身媒合平台

Core Concept

專為台灣 2025 超高齡社會設計的「Uber-for-Health」居家運動媒合平台。鎖定「肌少症長者」與「洗腎患者」，透過媒合物理治療師與專業教練進入居家場域，解決醫療後端與居家前端的斷層。

解決市場痛點
  • 解決長者與洗腎患者出門就醫復健的不便
  • 改善偏鄉醫療資源不足與家庭照護崩潰問題
  • 透過精準阻力訓練，提升洗腎效率並降低骨折風險
Key Features
子母帳號機制子女付費管理、長輩極簡操作，解決數位落差與信任問題。
醫療級 SOAP 紀錄導入標準化紀錄格式，確保教練與物理治療師跨專業無縫對接。
SOS 安全防護網一鍵求救連線與 GPS 定位，搭配電子訪視驗證 (EVV) 保障安全。
